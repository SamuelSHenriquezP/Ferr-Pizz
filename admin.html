6. Conexión de Base de Datos (Firebase Firestore) y Cloudinary CDN

Deja conectada tu base de datos gratuita para que cada cambio que publiques se actualice en todos los dispositivos al instante.

✦ 1. Base de Datos en Tiempo Real: Firebase Firestore (Plan Gratuito Spark)

Pega aquí el objeto firebaseConfig (en formato JSON) que te entrega la consola de Firebase al crear tu aplicación web. Al hacer clic en Vincular y Subir Base de Datos, toda la carta, precios, complementos y textos actuales se subirán a la colección ferpizz_cms/site_data.

¿Cómo crear y conectar tu Base de Datos Firestore en 3 minutos?

  1. Entra a console.firebase.google.com e inicia sesión con tu cuenta de Google.
  2. Haz clic en Crear un proyecto (ej. ferpizz-cartagena).
  3. En el menú lateral izquierdo, entra a Compilación → Firestore Database y haz clic en Crear base de datos.
  4. En las Reglas (Rules) de Firestore, coloca lectura pública y escritura abierta mientras administras: allow read, write: if true; y publica las reglas.
  5. Ve a la Configuración del Proyecto (ícono de engranaje) → sección Tus apps → elige el ícono Web (</>), regístrala y copia los datos de firebaseConfig en el cuadro de arriba.
  6. Para dejarlo fijo en el código al subir tu página a internet, pega ese mismo bloque en la variable PRODUCTION_FIREBASE_CONFIG al inicio del archivo cms-data.js.
